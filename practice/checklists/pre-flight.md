# SANDBOX PRE-FLIGHT CHECKLIST

Complete EVERY item before starting any practice session.

## Environment Check
- [ ] I am running in the bionic_daughter_agent/sandbox/ directory
- [ ] No production systems are accessible from this environment
- [ ] I have verified the target is isolated (VM, container, or local-only)
- [ ] I have a way to clean up after the session (kill processes, remove files)

## Authorization Check
- [ ] I own this target OR have explicit written permission to test it
- [ ] I know what the target is and which version I'm practicing on
- [ ] I understand that testing unauthorized systems is wrong and possibly illegal

## Knowledge Check
- [ ] I have read the relevant vulnerability class in hacking_exploit_api_sql_mastery.md
- [ ] I understand the theory behind the vulnerability I'm practicing
- [ ] I have identified the specific vulnerable code in the target
- [ ] I know what a successful exploit looks like (so I can recognize it)

## Safety Check
- [ ] I have a plan to STOP if something behaves unexpectedly
- [ ] I will not use any tool or technique I don't understand
- [ ] I will not escalate beyond what I'm practicing without explicit intent
- [ ] I will document EVERYTHING (successes AND failures)

## Cleanup Check
- [ ] I know how to shut down the target after practice
- [ ] I will remove any temporary files I created
- [ ] I will record my session notes before cleaning up
